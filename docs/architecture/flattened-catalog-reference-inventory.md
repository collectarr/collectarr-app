# Flattened Catalog Reference Inventory (App)

This inventory records the current App feature surfaces that carry a Work/Release identity or personal data. The destinations below preserve useful user data using Catalog Item references and independent App collection items. They do not claim the cutover is complete.

The pinned kind-owned Catalog Item field contract is tool/core_contracts/catalog-item-v1.json. After updating it from Core with tool/update_core_contracts.ps1, regenerate App's field-name projection with dart run tool/generate_catalog_item_v1_fields.dart. The generated file carries the pinned schema hash and is checked in CI.

The Music ledger is `music-catalog-field-inventory.md`. The provisional ledgers for Anime, Board Game, Book, Comic, Game, Manga, Movie, and TV are in `catalog-item-field-ledgers/`. Their Core/App keys and schema types are recorded, but their displayed labels, edit tabs, repeat behavior, and CLZ parity remain unverified until the corresponding Edit-form captures are available.

## Personal-reference contract

The final model stores canonical metadata against a `CatalogItemRef` and personal data on an App collection item identified by `CollectionItemRef(kind, id)`. The collection item stores its `catalogRef` separately; its identity does not repeat the Catalog Item ID. A user can create multiple collection items that share the same catalog metadata, each with its own personal fields. Retained kind-owned children use an explicit child identity owned by that kind; they are never represented as a synthetic Work or Release. Quantity aggregation is not part of the collection-item model.

The final runtime does not decode or remap old Work/Release/Copy references, old Smart List criteria, or old preference formats. Existing databases and backups in those formats are unsupported by the v1 baseline. During implementation, keep any still-active Work/Release feature until its consumer has been replaced; do not mistake that active feature for a compatibility path and do not add a migration adapter for it.
